Qaraqalpagim — restaurant website demo

Run locally by opening index.html through a local static server so menu.json can be fetched.
For example: python -m http.server 8080

Included:
- Russian-language restaurant landing page
- Responsive desktop/mobile layout
- Menu categories + search + reset
- Menu cards with names/prices only (no food photos)
- Product details modal
- Working localStorage shopping cart
- Quantity controls + automatic total
- Delivery form: name, phone, address, comment
- Reservation form: name, phone, guests, date, time, comment
- Mobile navigation drawer
- Separate menu.json for easy future editing
- Qaraqalpagim logo asset from the provided menu photos

Note: order and reservation submission are demo/local flows. They do not send data to a server.
